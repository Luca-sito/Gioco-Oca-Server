01

Requisiti generali

Per utilizzare Giochi Società è necessario disporre di un dispositivo con accesso a internet e di un browser moderno compatibile con le tecnologie web utilizzate dalla piattaforma.

Il servizio è progettato per funzionare direttamente tramite browser, senza richiedere l'installazione di programmi aggiuntivi.

💡 Per una migliore esperienza è consigliato mantenere il dispositivo e il browser aggiornati.
02

Browser supportati

Per utilizzare correttamente Giochi Società sono consigliati browser moderni e aggiornati, tra cui:

  • Google Chrome, versione recente;
  • Mozilla Firefox, versione recente;
  • Microsoft Edge, versione recente.
💡 Per evitare problemi durante le partite online è consigliato utilizzare sempre l'ultima versione disponibile del browser.
03

04

Connessione internet

Giochi Società è una piattaforma multiplayer online che utilizza comunicazioni in tempo reale per sincronizzare le attività di gioco tra i partecipanti.

È quindi necessaria una connessione internet sufficientemente stabile.

  • Connessione minima consigliata: 5 Mbps;
  • Ping contenuto consigliato per una maggiore fluidità durante le partite;
  • Evitare, quando possibile, reti molto instabili o soggette a frequenti disconnessioni.
🌐 Una connessione stabile è particolarmente importante durante le partite multiplayer in tempo reale.
05

JavaScript e tecnologie necessarie

Per il corretto funzionamento della piattaforma è necessario che JavaScript sia abilitato nel browser.

Giochi Società utilizza tecnologie web moderne per gestire l'interfaccia, le comunicazioni in tempo reale, le lobby, le partite online e le funzionalità disponibili agli utenti.

⚙️ La disattivazione di JavaScript o il blocco di alcune tecnologie del browser può impedire il corretto funzionamento del servizio.
06

Prestazioni consigliate

Per ottenere un'esperienza più fluida durante l'utilizzo della piattaforma si consiglia di:

  • Disporre di almeno 4 GB di RAM disponibili;
  • Utilizzare un dispositivo aggiornato;
  • Chiudere programmi o applicazioni particolarmente pesanti durante le partite;
  • Utilizzare una connessione internet stabile;
  • Mantenere aggiornati il sistema operativo e il browser.
07

Risoluzione problemi

Se la piattaforma o una partita non funzionano correttamente, è consigliato effettuare alcune verifiche di base.

  • Aggiornare il browser all'ultima versione disponibile;
  • Controllare che la connessione internet sia stabile;
  • Verificare che JavaScript sia abilitato;
  • Disabilitare temporaneamente eventuali estensioni che bloccano script o connessioni;
  • Ricaricare la pagina e riprovare ad accedere alla partita.
🔧 Se il problema persiste anche dopo queste verifiche, è possibile contattare lo staff per ricevere assistenza.
08

Contatti

Per segnalare problemi tecnici, incompatibilità o difficoltà nell'utilizzo della piattaforma puoi contattare lo staff tramite i canali indicati sul sito.
